# ZInitiatives maintenance rules

ZInitiatives is the shared GitHub Registry, not an Initiative content repository. Keep manifest inputs under `registry/`, generated projections under `generated/`, protocol schemas under `schemas/`, and protocol documentation under `docs/prds/`.

The hierarchy is exactly `Initiative → Spec → Plan`. Manifest paths point to files in the Initiative repository and never contain local absolute paths or credentials. Generated files are derived from manifests and must be regenerated by the compiler when that implementation exists.

Read [Initiative Registry Protocol](docs/prds/initiative-registry-protocol.md) before changing schemas, manifest fields, generated outputs, or path rules. Validate JSON syntax, schema constraints, cross-manifest references, and `git diff --check` before handoff.
